Bridge

Safety

Safe mode is on by default and cannot be turned off in this build. The extension has no code path that could clear a CAPTCHA, log in, or evade a rate limit, and a page that presents one is reported as blocked for a person to resolve.

Grok concurrency is fixed at 1. Browser generation is a single interactive session, so a second concurrent job would type into the same prompt field as the first.
