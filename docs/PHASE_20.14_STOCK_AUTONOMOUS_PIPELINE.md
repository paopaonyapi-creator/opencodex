# Phase 20.14 / 21.1: End-to-End Autonomous Stock Production & Submission Pipeline

## 1. Executive Summary

This phase unifies the entire Pao-hubPro autonomous production and commercial submission lifecycle into a singular, cohesive multi-agent pipeline engine (`StockAutonomousPipelineEngine`).

Prior phases built individual, specialized subsystems:
- **Phase 20.10**: Trend Research & Niche Opportunity Intelligence (`TrendResearchOrchestrator`)
- **Phase 21**: Campaign Portfolio Planning (`CampaignPlanner`, `NicheViabilityScorer`)
- **Phase 19 / 20**: Generative Grid & GPU Workload Dispatch (`CampaignDispatcher`, `ComfyUI/MiniMax/SeedStory`)
- **Phase 20.4 / 21**: Visual Quality Control & IP Sanitizer (`VisualQcGate`, `IpSanitizer`, `ReviewerCouncil`)
- **Phase 20.13**: Browser Multi-Agent Web Submission Squad (`BrowserMultiAgentCoordinator`, `UploadWebAgent`, `QAWebAgent`, `ReviewerWebAgent`)
- **Phase 20.11 / 20.14**: Remote Browser Worker & Human Supervisor Approval Gate (`BrowserApprovalManager`, `RemoteJobDispatcher`)

Phase 20.14 bridges these disparate components into a **7-Stage Deterministic Workflow** executed under strict **Human Supervisor Governance** (Level 3 `CONFIRM_REQUIRED`).

## 2. Architecture & The 7-Stage Pipeline

```
  [Stage 1: Trend Discovery]
              │ (Opportunity Score, Commercial Concept)
              ▼
  [Stage 2: Campaign Portfolio Planning]
              │ (10/20-shot Diversified Shot Matrix)
              ▼
  [Stage 3: Generative Batch Dispatch]
              │ (GPU Queue, Provider Routing, Seed Sync)
              ▼
  [Stage 4: Automated QC & IP Sanitizer]
              │ (Resolution 4MP+, Sharpness, Trademark Scan, Council Verdict)
              ▼
  [Stage 5: Adobe Stock CSV Manifest Packaging]
              │ (Title, Keywords, Category, Release, Compliance Formatting)
              ▼
  [Stage 6: Browser Multi-Agent Web Preparation]
              │ (Squad Dispatch, Strict File Allowlist Check, DOM QA Audit)
              ▼
  [Stage 7: Human Supervisor Approval Gate & Submission]
              │ (Approve Once / Session / Reject / STOP AGENT)
              ▼
       [Live Portfolio Submission]
```

### Stage Breakdown

1. **Stage 1: Trend Discovery (`stepTrends`)**
   - Dispatches research query to `TrendResearchOrchestrator`.
   - Computes commercial opportunity score (0–100) and recommendation tier.
   - Extracts top commercial concept with industry targeting and prompt blueprints.

2. **Stage 2: Campaign Planning (`stepPlanCampaign`)**
   - Formulates a 10-shot or 20-shot diversified campaign matrix.
   - Assigns aspect ratios, lighting conditions, angles, and provider allocations.
   - Persists campaign record and items in `stock_campaigns` and `stock_campaign_items`.

3. **Stage 3: Generative Dispatch (`stepDispatchGeneration`)**
   - Automatically dispatches planned items into `gen_jobs` queue.
   - Syncs GPU batch rendering progress and records job tracking identifiers.

4. **Stage 4: Automated QC & IP Clearance (`stepRunQc`)**
   - Enforces Adobe Stock technical quality benchmarks: 4.0 MP+ resolution, crispness threshold, artifact penalty.
   - Executes trademark and likeness scanning against protected brands.
   - Records consensus verdicts in `stock_qc_records` via Reviewer Council.

5. **Stage 5: Adobe Stock CSV Manifest Packaging (`stepPackageManifest`)**
   - Generates compliant CSV manifest matching Adobe Stock Contributor specifications: `Filename, Title, Keywords, Category, Releases`.
   - Formats SEO metadata generated by Metadata Agent.

6. **Stage 6: Browser Squad Preparation (`stepPrepareBrowserMission`)**
   - Creates a Multi-Agent Web Mission (`BrowserMultiAgentCoordinator`).
   - Assigns Squad personas: Research, Metadata, Upload, QA, and Reviewer Council.
   - Verifies asset file paths against the strict **File Allowlist** (`/approved/assets/`, `/uploads/`, `artifacts/`).
   - Formulates structured Reviewer Council proposal and registers Human Approval Request (`browser_approvals`).
   - Transitions pipeline status to `waiting_approval`.

7. **Stage 7: Human Supervisor Gate (`stepFinalizeSubmission`)**
   - Operator reviews the proposal with visual proof and manifest details.
   - **Approve**: Unlocks submission, marks status `completed`.
   - **Reject**: Aborts submission, records operator rationale, marks status `cancelled`.

## 4. Canonical MCP Tools

Exposed under the `stock.pipeline.*` namespace:
- `stock.pipeline.run`: Run entire pipeline end-to-end until supervisor gate.
- `stock.pipeline.create`: Initialize a pipeline run in pending state.
- `stock.pipeline.get`: Fetch detailed stage outputs, QC stats, and manifest data.
- `stock.pipeline.list`: Query past runs with status filtering.
- `stock.pipeline.step`: Trigger or advance an individual stage (1 to 6).
- `stock.pipeline.finalize`: Approve or reject the Stage 7 Human Supervisor Gate.
- `stock.pipeline.cancel`: Cancel an active or waiting pipeline run.

---

## 5. Management REST API Endpoints

Mounted under both `/api/stock/pipeline/*` and `/api/agent-os/stock/pipeline/*`:
- `POST /api/stock/pipeline/run` — trigger end-to-end execution.
- `POST /api/stock/pipeline/create` — create run record.
- `GET  /api/stock/pipeline/runs` — list pipeline runs.
- `GET  /api/stock/pipeline/runs/:id` — get status and stage summaries.
- `POST /api/stock/pipeline/runs/:id/step` — execute single stage.
- `POST /api/stock/pipeline/runs/:id/finalize` — submit operator decision (`approve`/`reject`).
- `POST /api/stock/pipeline/runs/:id/cancel` — abort pipeline run.
